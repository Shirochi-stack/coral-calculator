## Page brawl: one dash button

- **The dodge is part of the dash:** the dodge button is gone, and the one dash button on the right does it all. On the ground it dashes, or hops back if you hold away; in a jump it dashes through the air. Each dash now starts with the dodge's moment where nothing can touch her, with the same short rest before the next. A dash pressed during the rest is just a dash, and its button looks a little softer meanwhile.
- **A new icon for it:** a figure leaning into a run, facing the way she dashes, instead of the skip arrows.
- **Keyboard:** O is now a second dash key, alongside Shift.
- A blow slipped by a dash still counts toward Halgakos's dodge lines.
