## A new name: Halgakos: Sloppy Copy

- **The app is now called Halgakos: Sloppy Copy,** and just "Halgakos" under its icon. It's the same app, and it installs over the old one with everything kept.
- **Ready for Google Play Games on PC:** the app no longer requires a touchscreen. Keyboard controls for Plus run and Page brawl come in the next updates.

## Download

Download **Halgakos-Sloppy-Copy-3.32.1.apk** below and open it on your Android device. It installs over Halgakos Calculator 1.2.0 to 3.32.0.

Requires Android 8.0 or later. This is a debug-signed preview build.

Only the APK is needed to install. `SHA256SUMS.txt` is available for optional download verification. The code is licensed under [MIT](https://github.com/Shirochi-stack/coral-calculator/blob/master/LICENSE), with a copy included below; the Halgakos artwork is not.
