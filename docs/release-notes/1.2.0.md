## A new app ID, for Google Play

Halgakos Calculator is on its way to Google Play, and for that its internal ID has changed from `com.coral.calculator` to `com.halgakos.calculator`. Nothing about how it works has changed since 1.1.4.

**What this means when you install it:** Android treats 1.2.0 as a different app from every earlier release, so it installs **beside** your current one instead of over it.

- Your history, memory and settings stay with the old app and do not carry over. Copy anything you need first.
- Uninstall the old Halgakos (or Coral) Calculator once you have 1.2.0, or you will have two.
- Android asks again for permission to display over other apps, as it does for any new app.

From here on, updates install over 1.2.0 as usual. The Google Play version and these GitHub builds are signed with different keys, so one cannot update the other: stay with whichever you installed.

## Download

Download **Halgakos-Calculator-1.2.0.apk** below and open it on your Android device.

Requires Android 8.0 or later. This is a debug-signed preview build.

Only the APK is needed to install. `SHA256SUMS.txt` is available for optional download verification. The code of Halgakos Calculator is licensed under [MIT](https://github.com/Shirochi-stack/coral-calculator/blob/master/LICENSE), with a copy included below; the Halgakos artwork is not.
